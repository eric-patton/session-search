Each feature owns its canonical `spec.md` under `spec/features/`. The files
`product.md`, `dashboard.md`, `analyze-product.md`, and `view.html` are generated.
Run `node scripts/assemble.mjs`, `node scripts/dashboard.mjs`, and
`node scripts/view.mjs` to refresh them. The files `constitution.md` and
`product-global.md` are maintained only on the main branch. Start a feature with
`/spec-flow:feature`.
