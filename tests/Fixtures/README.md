# Sanitized provider fixtures

These files model recognized Claude Code and Codex shapes without copied user
content. Tests copy them to isolated temporary roots before mutation scenarios.
Oversized records, junctions, ACL variants, SQLite sidecars, held locks, partial
lines, and migration failures are generated by tests so the repository never
contains a large or machine-specific artifact.

Provider fixture files are read-only inputs. Tests capture SHA-256, byte length,
and last-write time before public operations and compare them afterward.
